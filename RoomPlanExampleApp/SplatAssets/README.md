# Apple plant scan

`plant.ply` is the real potted-plant Gaussian scan supplied with Apple's
“Rendering Gaussian splats with RealityKit” sample. It contains 51,352 splats.
It is an object capture, not a Roomy room scan or a synthetic test fixture.

Source: https://developer.apple.com/documentation/visionos/rendering-gaussian-splats-with-realitykit

Archive: https://docs-assets.developer.apple.com/published/322d76059013/RealityKitGaussianSplats.zip
